# v1.1 非技术交接：这个项目现在是什么

## 一句话定位

竞域不是一款有画面的游戏，而是“战斗之外的竞技游戏后台模块”：玩家连接后，它负责断线恢复、1v1 匹配、房间准备、接收可信战斗结果、保存成绩和维护排行。

## 你现在能实际看到什么

启动 Lab：

```bash
./scripts/demo-up.sh --lab
```

打开 <http://127.0.0.1:49140/>。你不需要懂 C++，只需要按这条路线看：

1. “服务概览”确认后台、数据库、缓存和故障代理是否可用。
2. “场景实验台”选择一种测试，修改页面允许的参数。
3. 点击运行后进入“运行详情”，先看大状态是否通过，再展开事件、断言和业务证据。
4. 点击重放会创建新运行；它证明相同输入仍满足相同业务规则，不要求内部编号完全一样。

Observer 位于 <http://127.0.0.1:49120/>，只负责看服务状态，不能创建测试或修改数据。

## 五种测试分别证明什么

- 完整对局：多名真实 TCP 玩家能被配成双人房间，并经过可信结果、MySQL 结算和 Redis 排行。
- 断线恢复：短时掉线能续上原会话，超过窗口会被稳定拒绝。
- 重复玩家请求：网络重发不会让同一操作执行两次。
- 重复可信结果：战斗服重发同一结果不重复加分，冲突结果会被拒绝。
- Redis 故障恢复：缓存坏掉时 MySQL 成绩仍然可信，缓存恢复后能自动追上。

## 哪些东西仍然没有

没有游戏画面、角色移动、技能、战斗同步，也没有账号、支付、聊天、公会或反作弊。Lab 只适合本机开发/QA，不适合放到公网让多人共用。
